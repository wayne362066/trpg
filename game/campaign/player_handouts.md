# 附錄 A｜可直接給玩家的 Handout

## A1. 七日倒數卡

| 日 | 玩家可見提示 |
| --- | --- |
| 第 1 日 | 有人在傷患名單上寫下：「距離第七日，尚有七天。」 |
| 第 2 日 | 雙方都聲稱自己遭到「對方」襲擊。 |
| 第 3 日 | 一名自稱守門人的人開始提供答案。 |
| 第 4 日 | 前任勇者的舊案例出現：犧牲一人，確實曾成功。 |
| 第 5 日 | 停戰與政治支持同步逼近極限。 |
| 第 6 日 | 你們掌握的情報開始彼此矛盾。 |
| 第 7 日 | 不再有「以後再查」。你們必須選擇。 |
