# 七日誓約｜創角規則

## 3. 創角建議

玩家角色可以是神官、學者、軍官、醫者、外交人員、邊境居民、魔族使節，或其他合理身分。建議至少一名 PC 具有與教廷、神術或古代誓約接觸的理由；GM 可在開團前私下指定其中一名 PC 為「誓約核心角色」，但不要提前告知其真正意義。

| 面向 | 推薦方向 | 提醒 |
| --- | --- | --- |
| 知識／調查 | 歷史、宗教、魔法、文獻、觀察 | 能幫玩家辨認「事實」與「後人解釋」的差別。 |
| 醫療／人道 | 治療、藥理、照護 | 是跨陣營信任的強力入口，但不必由同一人包辦。 |
| 社交／政治 | 交涉、洞察、禮法、談判 | 不是「魅力高就洗腦」，而是理解對方需要什麼。 |
| 戰鬥／護衛 | 近戰、追蹤、壓制 | 本作可以完全零戰鬥，但有人能處理安全問題會讓調查更自由。 |
| 弱點 | 請保留至少一個明顯短板 | 本作鼓勵依賴隊友；全能角色反而較少形成有趣分工。 |

## 4. 個人物件鉤子

每名玩家可自訂一件「看似只是角色風味」的隨身物件：護符、舊戒指、家書、刻印、折損的宗教飾品、家族紀念品等。GM 可以選擇其中一件，在不改變玩家原意的前提下，讓它成為後續調查線索。原則是「回收玩家提供的素材」，而不是偷偷把角色背景改造成另一個人。

# 附錄 C｜快速預生成角色建議

| 角色 | 強項 | 弱點 | 私人鉤子 |
| --- | --- | --- | --- |
| 年輕神官／醫者 | 醫療、神聖感知、同理 | 體魄差或缺乏政治經驗 | 一件從小帶著、自己也說不清來歷的宗教物件。 |
| 王國調查官 | 觀察、法規、追蹤 | 對魔族偏見或過度重證據 | 曾在偽裝襲擊中失去熟人。 |
| 魔族使節／醫者 | 魔族知識、交涉、藥理 | 在人類領地缺乏安全感 | 知道一項人類沒有的醫療技術。 |
| 學者／檔案員 | 學識、古文、誓約研究 | 戰鬥弱、容易被權威資料誤導 | 手上有一份跟現行版本不一致的舊祈禱詞。 |
| 護衛／騎士 | 戰鬥、保護、威懾 | 容易把「我來承擔」當責任 | 曾被教育「保護別人就是把自己排在最後」。 |

> 多人團改編 若 3–5 名玩家一起跑，不必把所有核心都塞到同一名「露比型」PC 身上。可以把醫療、政治、學識、誓約共鳴分散給不同 PC，讓 True End 真正需要團隊拼圖。

## 2. 原始創角流程

步驟一：擲 5 次 d6，記下五個結果。

步驟二：玩家自由把這五個數字分配給「體魄、靈巧、學識、洞察、意志」。

玩家不能改變骰出的數字，但可以決定自己要把強項與弱項放在哪裡。低能力值不是做壞角色，而是鼓勵玩家換方法、合作、借力或承擔代價。

步驟三：擲 1d12，記錄「神眷」。神眷獨立於五項基礎能力，不可與它們交換。

步驟四：正式導入前擲 1d20 作為開局特殊骰。原測試團曾擲出 11；此骰的具體世界偏移效果屬新版可選規則，GM若未使用相關表格，僅記錄結果即可，不必硬套效果。

## 3. 五項基礎能力

| 能力 | 涵蓋範圍 | 常見例子 |
| --- | --- | --- |
| 體魄 | 力量、耐力、承受身體負荷 | 撐門、搬運、長途追趕、抵抗肉體傷害 |
| 靈巧 | 精細操作、速度、潛行、手上技巧 | 換物、開鎖、閃避、偽造外觀 |
| 學識 | 歷史、宗教、文獻、理論理解 | 辨認古文、比對記錄、理解儀式 |
| 洞察 | 觀察、判斷矛盾、讀人與情勢 | 察覺說詞不對、找異常、理解動機 |
| 意志 | 精神韌性、信念、抵抗恐懼與干涉 | 承受誓約壓力、抗誘惑、保持清醒 |
