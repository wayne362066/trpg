# 第九部｜可選支線與備援 NPC

| NPC／支線 | 用途 | 若不跑怎麼辦 |
| --- | --- | --- |
| 塞維爾神父（艾德師父） | 舊版教廷口傳、舊祈禱詞中的「選擇」語義 | 主教舊檔或玩家自行研究可替代。 |
| 米拉（邊境偵察隊長） | 早期 false flag 證據：武器、撤退路線、目標價值不合理 | 卡西安＋艾莉西亞直接核對也可推出。 |
| 奧斯溫（教廷檔案官） | 證明封存規定沿用數百年、原始授權早已失效 | 主教可直接帶回同類證據。 |
| 奧德里克公爵 | 艾莉西亞的強硬政治對手；迫使和平派拿實績而非口號 | 若不跑，GM只需抽象化為「王都反對派」。 |
| 雷納德騎士長 | 伊蕾娜隱瞞 vs 王國知情權；可轉成王都軍事盟友 | 完全不跑也不影響主線，王都需玩家自己追。 |
| 年輕魔族受害者 | 讓 false flag 的「假襲擊、真仇恨」具象化 | 可用背景敘述代替。 |
