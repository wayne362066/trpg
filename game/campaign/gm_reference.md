# 七日誓約｜GM 參考索引

本文件只供 GM LLM 使用，不直接提供給玩家。需要時依場景讀取以下文件：

- `timeline.md`：七日倒數與每日壓力。
- `npcs.md`：主要 NPC 基礎設定與演法。
- `secrets.md`：核心謎題與世界真相。
- `clues.md`：線索、替代入口與 Fail Forward。
- `hidden_state.md`：Flag、信任與幕後狀態。
- `conflicts.md`：戰鬥觸發與非戰解法。
- `side_npcs.md`：備援 NPC 與可選支線。
- `ending_tree.md`：結局條件與結果。
- `relationships.md`：可選人際／戀愛分支。
- `gm_checklist.md`：Session 0、日結與結團檢查。
- `ai_campaign_protocol.md`：本劇本的 AI GM 演法。
- `dice_rules.md`：四骰規則。
